# AI Implementation Prompt

Implement exactly one DepRail issue. Read the linked PRD, requirements, issue, and dependency contracts first. Present a brief plan before editing. Do not change schemas, public interfaces, tool versions, security boundaries, or unrelated files without explicit approval. Preserve deterministic output, complete failure semantics, path containment, safe subprocess rules, stdout/stderr separation, and evidence provenance.

Deliver code, tests, documentation, and verification evidence together. Run the issue's required commands and `make verify`. Report changed behavior, files, commands and results, contract decisions, remaining risk, and any item that still requires human review. Never claim a test passed unless it was run.
