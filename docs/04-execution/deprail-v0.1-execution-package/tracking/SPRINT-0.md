# SPRINT 0 Checklist Engineering Baseline One Week

## Goal

Create a reproducible repository, contracts, fixtures, CI, and execution rules.

## Committed

- [ ] `S0-001`
- [ ] `S0-002`
- [ ] `S0-003`
- [ ] `SCHEMA-001`
- [ ] `FIXTURE-001`

## Daily Control

- [ ] WIP is at most two implementation items and two review PRs.
- [ ] Every blocker has an owner and next-check date.
- [ ] Required evidence is added as work progresses.
- [ ] Contract and risk changes are escalated immediately.

## Manual Tests

- [ ] Run the Sprint demo from a clean environment.
- [ ] Exercise at least one incomplete or adversarial case.
- [ ] Confirm output and diagnostics are separated and free of secrets.

## Exit

- [ ] Sprint goal is demonstrated.
- [ ] All committed issues meet Definition of Done or are explicitly re-planned.
- [ ] `make verify` and required platform checks pass.
- [ ] Documentation and tracking are current.
- [ ] Human review records the decision and remaining risk.
