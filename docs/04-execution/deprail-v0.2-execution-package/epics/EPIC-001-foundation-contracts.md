# EPIC-001 Foundation and Contracts
**GitHub epic:** [#106](https://github.com/geoffrey-xiao/deprail/issues/106)

## Outcome

Close the highest-risk v0.1 contract gaps before adding product breadth.

## Scope

- Empty collection serialization.
- Strict command arguments.
- Version/tag/commit identity.
- Workflow and release-mode documentation.

## Non-goals

No new scanner family, hosted service, remediation, or schema-breaking change.

## Acceptance

All P0 contract gaps have consumer-visible tests, stable error behavior, updated examples, and linked evidence.

## Issues

- `V02-001` Normalize empty report collections.
- `V02-002` Reject unexpected command arguments.
- `V02-003` Inject truthful build version identity.
- `V02-004` Establish release-mode evidence checklist.
