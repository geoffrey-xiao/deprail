# EPIC-004 Release Quality

## Outcome

Make every v0.2 candidate identifiable, reproducibly verifiable, and honest about supply-chain gaps.

## Scope

- Preview/RC/stable release modes.
- Tag, manifest, CLI identity, and artifact consistency.
- Cross-platform artifacts and smoke evidence.
- Checksums, manual repository scans, SBOM status, signing status, and rollback evidence.

## Acceptance

A release candidate cannot be described as stable without complete linked evidence and an owner decision on remaining risk.

## Issues

- `V02-011` Verify release identity across artifacts.
- `V02-012` Add release-mode smoke and evidence procedure.
- `V02-013` Record artifact, checksum, SBOM, signing, and manual-scan evidence.
