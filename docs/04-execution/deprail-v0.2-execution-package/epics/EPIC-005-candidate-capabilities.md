# EPIC-005 Candidate Capabilities

## Outcome

Evaluate possible v0.2 breadth without allowing unapproved features to enter implementation.

## Candidates

- Baseline comparison.
- Policy gates.
- SARIF output.
- Additional scanner ecosystems.
- SBOM generation and signing.
- Remote publishing/history.

## Gate

Each candidate requires a decision issue with user value, scope, dependencies, compatibility, security impact, failure behavior, acceptance evidence, and reviewer. No candidate is implementation-ready until the PRD and requirements package are amended.

## Issue

- `V02-014` Decide the v0.2 candidate capability boundary.
