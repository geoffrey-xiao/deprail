# v0.3.1 Master Checklist

## Planning and review

- [ ] Development plan reviewed against roadmap, product, architecture, and v0.3 evidence.
- [ ] PRD, architecture package, requirements, and test strategy reconciled.
- [ ] Presentation event vocabulary and renderer boundary approved.
- [ ] CLI stream, TTY, JSON, quiet, verbose, and exit contracts approved.
- [ ] Hostile-label, redaction, cancellation, and dependency risks reviewed.
- [ ] Acceptance matrix and manual evidence scenarios approved.
- [ ] Definition of Ready recorded by owner and reviewer.

## Implementation gate

- [ ] Implementation issues created only after planning approval.
- [ ] No scanner, domain, mutation, network, or schema-breaking scope added without change control.

## Release gate

- [ ] Unit, contract, golden, integration, and cross-platform evidence complete.
- [ ] Interactive, redirected, JSON, quiet, verbose, partial, failed, narrow, monochrome, hostile-label, and cancellation scenarios captured.
- [ ] General release checklist complete.
- [ ] Owner approval recorded.
- [ ] Architecture/security review recorded.
- [ ] Retrospective prepared.
