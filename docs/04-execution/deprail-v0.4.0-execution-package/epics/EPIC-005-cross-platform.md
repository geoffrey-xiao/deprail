# EPIC-005: Cross-Platform Acceptance Evidence

**Status:** Proposed

## Outcome

The v0.4 remediation workflow has reproducible acceptance evidence on Linux, macOS, and Windows.

## Boundaries

Includes fixed offline fixtures, hostile-path cases, permissions, process cancellation, cleanup, serialized-output comparison, and manual release evidence. Excludes platform-specific feature expansion.

## Acceptance

Required scenarios run on all supported platforms; only platform-neutral domain meaning is compared; deviations are documented and reviewed.
