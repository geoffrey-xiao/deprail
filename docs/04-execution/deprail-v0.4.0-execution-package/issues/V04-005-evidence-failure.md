# V04-005: Persist Patch Evidence and Failure Outcomes

**Epic:** EPIC-004
**Status:** Proposed; implementation blocked

## Scope

Define the versioned result schema, stable diagnostics, command/tool identity, before/after digests, diff metadata, content-addressed artifacts, redaction, and terminal outcomes.

## Acceptance

Evidence validates, excludes secrets, retains partial successful evidence, records cleanup state, and distinguishes applied, verified, partial, failed, cancelled, and cleanup-failed outcomes.
