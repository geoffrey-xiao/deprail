# V04-006: Prove Cross-Platform Acceptance Matrix

**Epic:** EPIC-005
**Status:** Proposed; implementation blocked

## Scope

Define fixed offline fixtures and manual evidence for isolation, hostile paths, atomicity, process limits, cancellation, cleanup, verification, rescan, and source immutability on Linux, macOS, and Windows.

## Acceptance

All required scenarios run on each platform. Evidence records binary identity, exact commands, exit codes, artifacts, tree comparison, reviewer, and remaining risk. Platform-specific paths and wording do not alter serialized domain meaning.
